# RAYKA SMS Forwarder

اپلیکیشن اندروید برای خواندن پیامک‌های تلمتری بویه از یک یا چند سیم‌کارت و ارسال آن‌ها به سرور Supabase (آنلاین)، با قابلیت ذخیره و ارسال به یک سرور محلی وقتی اینترنت قطع است (آفلاین)، و همگام‌سازی خودکار به محض بازگشت اینترنت.

## ساخت APK از طریق گیت‌هاب (بدون نیاز به Android Studio)

1. یک ریپازیتوری جدید در گیت‌هاب بساز (مثلاً `rayka-sms-forwarder`) و کل این پوشه را در آن push کن:
   ```
   git init
   git add .
   git commit -m "RAYKA SMS Forwarder"
   git branch -M main
   git remote add origin https://github.com/USERNAME/rayka-sms-forwarder.git
   git push -u origin main
   ```
2. وارد تب **Actions** در صفحه ریپازیتوری بشو. یک workflow به اسم "Build Rayka APK" خودش اجرا می‌شود (چون فایل `.github/workflows/build-apk.yml` در پروژه هست).
3. چند دقیقه صبر کن تا build سبز بشه. بعد روی همان اجرا (run) کلیک کن و پایین صفحه بخش **Artifacts** را باز کن — یک فایل `rayka-debug-apk` آنجا هست.
4. آن را دانلود کن، از حالت zip خارجش کن، فایل `app-debug.apk` داخلش هست.
5. آن APK را روی گوشی خودت کپی کن و نصبش کن (باید نصب از منابع ناشناس را برای همان اپ فایل‌منیجر/مرورگر فعال کنی).

اگر بعداً کدی را عوض کردی، فقط دوباره `git push` کن؛ Action خودش دوباره APK جدید می‌سازد.

## بعد از نصب روی گوشی

1. اپ را باز کن، در تب «داشبورد»:
   - آدرس سرور اصلی (Supabase edge function) و آدرس سرور محلی را وارد کن.
   - بازه زمانی بررسی/ارسال را تنظیم کن (۳ تا ۳۶۰۰ ثانیه) و «ذخیره تنظیمات» را بزن.
   - دکمه «گرفتن مجوز پیامک و نوتیفیکیشن» را بزن و مجوزها را قبول کن.
   - دکمه «غیرفعال کردن بهینه‌سازی باتری» را بزن (مخصوصاً روی MIUI ضروری است).
   - دکمه «روشن کردن سرویس ارسال» را بزن.
2. کلید «آنلاین» و «آفلاین» را می‌توانی همزمان روشن نگه داری — اپ خودش بر اساس وضعیت اینترنت تصمیم می‌گیرد کدام را استفاده کند.
3. در تب «گزارش پیامک‌ها» می‌توانی همه پیامک‌های دریافتی، زمان دریافت، زمان ارسال، و نوع ارسال (آنلاین / آفلاین / ذخیره‌شده و ارسال بعدی) را ببینی.

## محدودیت شناخته‌شده
تشخیص شماره اسلات سیم‌کارت روی برخی گوشی‌های MIUI ممکن است در دسترس نباشد؛ در آن صورت `-1` (نامشخص) ثبت می‌شود.
